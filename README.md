One word that sums up an ex — an entry for
[Describe Your Ex in One Word](https://make.fun/bounty/u-puan-describe-your-ex-in-one-word-9fc6ebe7) on make.fun.

## The word

> **unsubscribed**

Not a breakup, not a fight — just quietly cancelled, like a newsletter you
finally stopped paying attention to. No drama, no renewal, no reply-all.

## How it works

`main.ts` writes the word to `<MAKEFUN_OUTPUT_DIR>/entry.txt`
(default `/output`), exactly one word, no trailing newline.

```sh
node main.ts
```
